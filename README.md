# MIST OF RUINS 〜霧の遺跡〜 (Adventure0611)

ブラウザで動く PC 用 三人称冒険探索アクションゲームです。
霧に包まれた古代遺跡の谷を探索し、剣と魔法で魔導機構を討伐し、クリスタルを集めます。

## 遊び方

`index.html` をブラウザで開くだけで遊べます(インターネット接続が必要です。Three.js を CDN から読み込みます)。

ローカルサーバーで起動する場合:

```bash
# どちらか好きな方法で
npx serve .
# または
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開き、タイトル画面をクリックすると冒険が始まります。

## 操作方法

| 操作 | キー / マウス |
|---|---|
| 移動 | `W` `A` `S` `D` (または矢印キー) |
| 視点 | マウス(クリックでマウスキャプチャ、`Esc` で解放) |
| 歩く | `Shift` 押しながら移動 |
| 剣攻撃 | 左クリック / `J` / 右下の剣ボタン |
| 魔法ビーム | 右クリック長押し / `K` 長押し / ビームボタン長押し |
| ファイアボール | `2` / 炎ボタン |
| 回転斬り | `3` / 三爪ボタン |
| 回復 | `4` / 十字ボタン |
| バリア | `5` / 盾ボタン |
| ダッシュ | `Space` / 稲妻ボタン |

`Esc` でマウスを解放すると、画面右下のスキルボタンをマウスで直接クリックできます。

## ゲーム要素

- **魔法ビーム** — 視線方向にシアンの粒子ビームを照射。近くの敵に自動で吸い付き、継続ダメージを与える(MP消費)
- **剣戟コンボ** — 左右交互の斬撃と軌跡エフェクト。回転斬りは全方位攻撃
- **魔導機構(敵)** — 紫色に輝く浮遊コアと旋回する岩。プレイヤーを発見すると追跡してくる。倒すとスコア獲得
- **クリスタル収集** — フィールドに浮かぶ光るクリスタルを集めると MP 回復+スコア
- **探索フィールド** — 蛇行する川、苔むした遺跡群、燃える神殿、浮遊島、流れる雲、漂う光の粒
- **UI** — 円形ミニマップ(左上)、ルーンコンパス(左下)、HP/MP バー(下中央)、クールダウン付きスキルボタン(右下)

## 技術メモ

- 依存は [Three.js](https://threejs.org/) (r160, CDN) のみ。ビルド不要の単一 HTML ファイル
- 地形・水面・草の風揺れはプロシージャル生成(シェーダー)
- 効果音は WebAudio によるリアルタイムシンセ(音声ファイル不使用)
- すべての動きはデルタタイムベース+指数減衰補間で、フレームレートに依存せず滑らかに動作
